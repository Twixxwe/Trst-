Methods

S1E 185 (stabilized Student-t)
Plain mean of each bridge's BPM differences. Each bridge is weighted by 1 ÷ (Student-t 95% CI half-width)². Before the CI is computed, the bridge's SD is blended with the pooled SD of all bridges as if it had 10 extra player-seasons: SD² = ((n − 1)·s² + 10·pooled²) ÷ (n − 1 + 10), with t at n − 1 + 10 degrees of freedom. This keeps a 2-player bridge with near-identical values from claiming false precision. No trimming, no ridge.
Unweighted 185
Plain mean of each bridge's BPM differences. Every bridge gets equal weight. No ridge.
Tested against games. With all leagues selected, this S1E 185 beat the plain Student-t version (14.47 vs 14.64 RMSE on 2,856 games) and the old Atlas S1E ladder. Pulling offsets toward game results made held-out predictions worse, so the ladder is built from crossovers only. League offsets have no CIs yet; only direct bridges do.

Bridges in this network

Difference = player's BPM in league B minus BPM in league A. A negative value means players post lower BPM in B, so B is the stronger league. Student-t CI = mean ± t(0.975, n − 1) × SD ÷ √n, using the bridge's own SD. The S1E weight uses the stabilized SD described above. Normal CI = mean ± 1.96 × SD ÷ √n. Both use SD with n − 1 and treat each player-season as independent. Bootstrap CI = 95% percentile interval from 1,000 resamples of players, keeping each player's seasons together (seed 185). Width = upper minus lower, in BPM points. One-player bridges have no interval.
